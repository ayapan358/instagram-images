# instagram-images

@kotomi_mensmind のInstagram自動投稿用の画像置き場です。
Instagramが画像を取りに来られるように、その日に投稿する画像（JPEG）だけを `YYYY-MM-DD/` に置きます。
画像は ayapan358/instagram-posts の定期タスクが自動で置きます。

## luna/
Luna Fortune（@luna_fortune_jp）の投稿用の画像・動画です。`luna/YYYY-MM-DD/` に置きます（ayapan358/instagram-posts の `luna/` から作ります）。kotomi の画像とは別の場所です。
